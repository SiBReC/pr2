# Практическая работа 1

Консольные программы на Python. Каждое задание - это каждый новый файл.

## Назначение проекта

Научиться делать консольные программы по правилам.

## Какие задачи решают программы

- `zad1.py` - Консольный калькулятор с базовыми операциями
- `zad2.py` - Конвертирует единицы измерения друг в друга
- `zad3.py` - Проверка числа на входе
- `zad4.py` - Считает стоимость товара, на который дается скидка

## Как запустить

Нужен Python 3. В папке с проектом в консоли:

```
python zad1.py
```

(вместо zad1.py пишем нужный файл)

Или же в PyCharm выбираем файл, открываем его и нажимаем на значок запуска.

## Как пользоваться

Запускаем файл и вводим то что просит программа. Если ввести не число, неизвестную операцию или делить на ноль, то программа напишет ошибку и завершится.

## Примеры работы

Калькулятор:
```

Введите операцию (+, -, *, /, //, %, ^): *

Конвертер:
```
