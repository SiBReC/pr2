# Практическая работа 2

Продолжение практической работы 1. Но вдобавок добавляется локальный Git. Добавить новые функции программе и закомиттить.

## Назначение проекта

Научиться делать консольные программы по правилам. Также научиться работать с Git и GitHub.

## Какие задачи решает программа

- `zad1.py` - Консольный калькулятор с базовыми операциями
- `zad2.py` - Конвертирует единицы измерения друг в друга
- `zad3.py` - Проверка числа на входе
- `zad4.py` - Считает стоимость товара, на который дается скидка
- 
## Новый функционал (практическая работа 2)

- **Калькулятор** - можно делать несколько вычислений подряд. После каждой операции программа спрашивает `Хотите выполнить ещё одну операцию? (да/нет)`. Если ввести не число, неизвестную операцию или делить на ноль, программа пишет ошибку и не вылетает, а работает дальше.
- **Конвертер** - несколько преобразований подряд (`Выполнить ещё одно преобразование? (да/нет)`). Добавлены новые преобразования: 5. Литры -> Галлоны, 6. Мегабайты -> Гигабайты, 7. Часы -> Минуты, 8. Рубли -> Доллары. Если на вопрос о продолжении ответить не да/нет, программа спросит еще раз.
- **Проверка числа** - можно проверять несколько чисел подряд. Добавлена проверка является ли число полным квадратом.
- **Покупка** - можно добавить несколько товаров в одну покупку. Проверяется что название не пустое, а цена и количество больше нуля. В конце выводится стоимость каждого товара, общая стоимость, скидка и итоговая стоимость.

## Как запустить

Нужен Python 3. В папке с проектом в консоли:

```
python zad1.py
```

(вместо zad1.py пишем нужный файл)

Или же в PyCharm выбираем файл, открываем его и нажимаем на значок запуска.

## Как пользоваться

Запускаем файл и вводим то что просит программа. Чтобы продолжить пишем `да`, чтобы закончить пишем `нет`.
